# Connected page groups for large documents

These instructions apply when task.page_group exists. All groups belong to the SAME original uploaded document, with original page numbers. The current conversation owns only page_group.owned_pages. Images/text from context_pages are preceding-page context, not additional rows to extract again.

- Acknowledge owned_pages in page_coverage, including covers and empty pages. Only emit material records and source_items for owned pages. Do not claim this group covers the whole file. Classification page hints may identify owned/context pages actually supplied.
- document_projects and boundary_records are saved same-run provisional context, not published facts. Reuse their actual project/proposal IDs where justified, without treating them as operational approvals. Cross-reference clues and previous descriptions can clarify the current page. Do not manufacture project details absent from source evidence.
- own_proposals can be omitted to keep the request within real context capacity. Use get_run_draft_context to retrieve THIS run's proposals or saved file material records; follow pagination, with no hidden ranked shortlist. All approved catalogue lookups remain available. Do not assume an omitted list is an empty catalogue or permission to propose duplicates blindly.
- A material record which CONTINUES an earlier table row can set continues_from to the exact backend-provided record_ref, such as PG-000001-000010:3. Retain the CURRENT original source_page and any source_item_ref printed on this page. Preserve the actual current description and source quantity/unit; do not copy invented item identifiers from a preceding page. State evidence for the continuation in issues/assumptions.
- Leave additional_source_pages empty during group extraction. Backend assembly fills verified continuation provenance from saved groups; do not claim context pages as newly extracted rows or manufacture same-group continuation references.
- A repeated table header/item copied for context is not another contribution. For a true continuation, emit the source-supported material values without adding them to the previous amount. If the previous amount was unknown, newly visible explicit evidence may complete it. Conflicting observations require human review, not arithmetic. Different genuine items sharing a material identity remain distinct, without continues_from.
- Several materials inferred from one source item remain separate material candidates with common source provenance. They are not continuations of each other. Whole-page images and detail tiles are views of the same page, not multiple contributions.
- Keep raw page references, stated versus inferred fields, quantity meaning and internal item accounting intact. Your group draft is saved separately. Only backend assembly after all required groups finish can produce the complete-file draft for reconciliation/review. No group can publish operational data.
