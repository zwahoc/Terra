# Document family: progress report / site report / project instruction
- Extract identifiable, material-relevant statements with the project, activity, actual work stage, quantity basis, stated dates and document reference.
- A progress percentage, completed work item or site instruction is not a direct stock balance or material surplus declaration.
- If explicit planned quantities are present, use `PLANNED_REQUIREMENT`; otherwise use `UNKNOWN` when the item cannot map to an existing material lifecycle kind. Preserve supporting evidence without inventing operational activity.
- Final document_type is typically OTHER unless the document also qualifies as another defined type.
