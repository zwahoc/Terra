# Document family: material certificate / technical data sheet / inspection
- Extract stated product/material identity, standards, size, grade, performance characteristics, test report references, batch numbers, dates and explicit pass/fail information only.
- Such documents usually do NOT establish construction demand, purchased amount, received goods, physical inventory or transferable surplus.
- Return no quantity/operational row if there is no material-relevant line to support one; do not invent a stock event just to populate records.
- Never infer engineering suitability, reusability, compliance certification beyond the source's actual assertion, or condition-management decisions. Top-level document_type is typically OTHER.
